# LMS-Project
A full-stack Learning Management System (LMS) with ASP.NET Core Web API backend and Next.js frontend, featuring authentication, course management, and user roles.

---

## 📌 Features

- User Authentication & Authorization
- Role-Based Access Control
- Course Management
- Student Dashboard
- Admin Panel
- RESTful API Integration
- Responsive UI
- File Upload Support
- Modern Frontend Architecture

---

## 🛠️ Tech Stack

### Frontend
- Next.js
- React.js
- Tailwind CSS
- TypeScript

### Backend
- ASP.NET Core Web API
- Entity Framework Core
- SQL Server
- JWT Authentication
